Welcome to Clarity

Clarity is a multilingual typography framework built exclusively on the Noto font family — with no system fonts used anywhere and Noto Sans Math placed last in the fallback chain to protect Arabic rendering.

Font Style Rules

  • Arabic Sans: Noto Sans Arabic — used automatically in /sansserif mode
  • Arabic Serif: Noto Naskh Arabic — used automatically in /serif mode
  • Rashi Hebrew: ONLY via /rashi command — never in fallback
  • Kufi Arabic: ONLY via /kufi command — never in fallback
  • Nastaliq Urdu: ONLY via /nastaliq command — never in fallback

Markdown Reference

  • # Heading · ## Heading · ### Heading · #### Heading — styled headings
  • - item or * item → bullet list
  • 1. item → numbered list
  • [Link Text](url) → clickable link
  • **bold** → weight 700 · *italic* → italic · ***bold-italic*** → both
  • `code` → monospace · ~~strike~~ → strikethrough
  • All Markdown is fully reversible — text returns to normal after block ends

Complete Fallback Order

Sans → Serif → Devanagari → Arabic Sans / Naskh Serif → Hebrew → Armenian → Deseret → Duployan → Sundanese → Dives Akuru → Tangut → Mono → Math → Emoji

Typography & Font Descriptions

Exclusive Command‑Only Fonts

Rashi Hebrew, Kufi Arabic, Nastaliq Urdu are special calligraphic styles that do NOT belong to the regular Sans or Serif fallback chains. They will only appear when explicitly activated by their command. This prevents them from being selected accidentally and ensures Arabic text uses the correct font (Sans or Naskh) by default.

Arabic Has Two Styles

Sans‑Serif Arabic: Noto Sans Arabic — modern, clean, used in /sansserif mode

Serif Arabic: Noto Naskh Arabic — traditional, calligraphic, used in /serif mode

Noto Sans Math remains at the very end of the chain — it will never break Arabic or any script.

Supported Writing Systems

Arabic Family

  • Noto Sans Arabic — Sans style, automatic in /sansserif
  • Noto Naskh Arabic — Serif style, automatic in /serif
  • Noto Kufi Arabic — Geometric, ONLY via /kufi
  • Noto Nastaliq Urdu — Urdu calligraphic, ONLY via /nastaliq

Hebrew Family

  • Noto Sans/Serif Hebrew — automatic in respective modes
  • Noto Rashi Hebrew — Rashi script, ONLY via /rashi

Command‑only fonts are excluded from general fallback to preserve correct typographic defaults.

Editor

Type text below. Commands change font style and are invisible in preview. Markdown is fully reversible.

Headings: # H1 · ## H2 · ### H3 · #### H4
Lists: - item / * item → bullet · 1. item → numbered
Links: [Link Text](url) → opens in new tab
Inline: **bold(700)** · *italic* · ***bold-italic*** · `code` · ~~strike~~
All Markdown is fully reversible — text returns to normal outside blocks.

Markdown Behavior

  • # Heading → styled heading with weight 700 — automatically ends at newline
  • - item / * item → bullet list — automatically ends at blank line or command
  • 1. item → numbered list — automatically ends at blank line or command
  • [text](url) → clickable link — opens in new tab
  • All Markdown works together with font commands: /serif ## Serif Heading

Command Reference

  • /serif → Serif fonts + Noto Naskh Arabic (Arabic Serif)
  • /sansserif → Sans fonts + Noto Sans Arabic (Arabic Sans)
  • /rashi /kufi /nastaliq → ONLY activate via command — never used automatically
  • /emoji → enable emoji · /noemoji → remove emoji from font chain

Commands apply to all text that follows until another command. Commands are hidden in preview output.

Axis Commands

Adjust weight, width, and italics for variable fonts. Markdown bold overrides axis weight when both are used.

Type commands above…
/wght 100–900 · /wdth 62.5–100 · /ital enable|disable · /normal reset

Variable axis commands do not apply to Rashi/Kufi/Nastaliq — these fonts have fixed axes.

Frequently Asked Questions

Why are Rashi/Kufi/Nastaliq only available via command? expand_more
These are calligraphic, decorative styles — not general‑purpose Sans or Serif. If placed in fallback chains, they would interfere with standard Arabic/Hebrew text. They are intentionally excluded from /serif and /sansserif so normal text uses the correct font automatically.
Does Arabic have both Sans and Serif? expand_more
Yes. Noto Sans Arabic is used in /sansserif mode. Noto Naskh Arabic is used in /serif mode — Naskh is the traditional serif‑style Arabic calligraphy.
What Markdown is supported and is it reversible? expand_more
Headings: # H1, ## H2, ### H3, #### H4
Lists: bullet (-/*) and numbered (1.)
Links: [text](url)
Inline: **bold(wght700)**, *italic*, ***bold-italic***, `code`, ~~strike~~
All Markdown is fully reversible — text returns to base style automatically after newline or end.
