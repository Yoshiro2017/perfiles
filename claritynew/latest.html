Welcome to Clarity

Clarity is a thoughtfully designed, fully self-contained single-file website framework built with pure HTML, modern CSS, and lightweight JavaScript. Everything you need — structure, styling, fonts, icons, behavior — lives in one file that you can open in any browser, host anywhere, or share without dependencies.

Built around Google’s comprehensive Noto font collection, Clarity offers native support for Latin, Armenian, Hebrew, Arabic, and Urdu writing systems. This means text renders beautifully across languages, with correct shaping, spacing, and directionality for every script included.

Beyond multilingual support, Clarity includes twelve carefully balanced color themes that you can switch instantly. Every theme maintains readable contrast, consistent spacing, and the same layout behavior — so your content stays accessible regardless of palette preference.

star Font Command System

One of Clarity’s most powerful features is its inline font command system. Simply type a command anywhere in your text, and every character that follows will render in the corresponding font — until you reset or switch to another. Commands themselves are invisible in the final output, so your content stays clean while retaining full typographic control.

  • /serif — Noto Serif (Latin/Armenian/Hebrew)
  • /sansserif — Noto Sans (default, all scripts)
  • /monospace — Noto Sans Mono (code, technical content)
  • /rashi — Noto Rashi Hebrew (traditional calligraphic style for emphasis)
  • /arabic — Noto Naskh Arabic (traditional reading style)
  • /kufi — Noto Kufi Arabic (geometric/decorative style)
  • /urdu — Noto Nastaliq Urdu (slanted calligraphic style)
  • /emoji — Noto Color Emoji
  • /noemoji or /normal — Reset to default font

palette Theme System

Every color in Clarity is defined through CSS custom properties, making the entire design theme-aware. Switching themes updates backgrounds, text, borders, shadows, and accents consistently across every page and component. Your theme preference is saved automatically in your browser and restored on return.

There are currently twelve themes available — from light and airy to high-contrast and expressive — each designed to preserve legibility and hierarchy. You can override any theme variable or create your own simply by adding a new data-theme block in the stylesheet.

code Why Single-File?

Keeping everything in one document offers practical advantages: zero build process, no external dependency issues, consistent rendering everywhere, and extreme portability. You can email it, put it on a USB drive, open it locally, or host it on any web server — and it will work exactly the same.

All styling is contained in one style block, all scripts in one script block, all content in one structure. This makes Clarity exceptionally easy to understand, modify, extend, or rebuild into something entirely your own.

translate Supported Scripts

Clarity includes fonts for five major writing systems, selected from the Noto collection for completeness and quality.

  • Latin — Sans, Serif, Display, and Mono variants covering nearly all Latin-based languages
  • Armenian — Both Sans and Serif forms, supporting both Eastern and Western orthography
  • Hebrew — Standard Sans, Serif, and the distinct traditional Rashi style
  • Arabic — Modern Sans, geometric Kufi for display, and traditional Naskh for extended reading
  • Urdu — Nastaliq, the calligraphic style widely used for Urdu and related languages
  • Emoji — Color emoji rendered consistently across all platforms

Right-to-left layout and baseline adjustments are handled automatically by the font files and styling, so Arabic, Hebrew, and Urdu text appears correctly without manual intervention.

The Noto Font Collection

The Noto project aims to provide high-quality fonts for all languages of the world, with harmonious design and comprehensive character coverage. Clarity pulls selected families from Google Fonts, carefully configured with full weight ranges, width variation, and italic styles where available.

Every font family loads asynchronously with a visual loading indicator, so you always know when each writing system is ready. Once loaded, fonts remain in memory while you navigate between pages.

Noto Sans Arabic

Arabic Script · Sans-Serif · Modern & Versatile

Noto Sans Arabic is a modern, upright sans-serif design suitable for general text, user interfaces, and continuous reading. It follows contemporary Arabic proportions and maintains excellent legibility across screen sizes and weights, making it ideal for web and digital interfaces.

يُولَدُ جَمِيعُ النَّاسِ أَحْرَارًا مُتَسَاوِينَ فِي الْكَرَامَةِ وَالْحُقُوقِ. وَقَدْ وُهِبُوا عَقْلًا وَضَمِيرًا وَعَلَيْهِمْ أَنْ يُعَامِلَ بَعْضُهُمْ بَعْضًا بِرُوحِ الْإِخَاءِ.

Noto Kufi Arabic

Arabic Script · Geometric Kufi · Bold & Decorative

Noto Kufi Arabic draws inspiration from the historic Kufi style, characterized by straight lines, geometric forms, and angular strokes. It works beautifully for headings, titles, logos, and decorative text — but is generally less suited for long paragraphs due to its stylized appearance.

يُولَدُ جَمِيعُ النَّاسِ أَحْرَارًا مُتَسَاوِينَ فِي الْكَرَامَةِ وَالْحُقُوقِ.

Noto Naskh Arabic

Arabic Script · Naskh · Traditional Reading Style

Naskh is one of the most historically important and widely used Arabic calligraphic styles. With balanced proportions, flowing curves, and excellent clarity, it remains the standard choice for books, religious texts, and extended reading.

يُولَدُ جَمِيعُ النَّاسِ أَحْرَارًا مُتَسَاوِينَ فِي الْكَرَامَةِ وَالْحُقُوقِ.

Noto Nastaliq Urdu

Urdu Script · Nastaliq · Slanted Calligraphy

Noto Nastaliq Urdu implements the Nastaliq style — a celebrated calligraphic tradition where each line slopes diagonally downward to the right. This creates the characteristic elegant, flowing appearance widely associated with Urdu poetry and literature.

تمان انسان آزاد پیدا ہوئے اور ان کی عزت اور حقوق میں برابر ہیں۔

Noto Sans Hebrew

Hebrew Script · Sans-Serif · Modern & Clear

Noto Sans Hebrew provides a clean, modern sans-serif form of the Hebrew alphabet, suitable for general content, interfaces, and daily reading.

כָּל בְּנֵי הָאָדָם נוֹלְדוּ בְּנֵי חֹרִין, וְשָׁוִים בְּעֶרֶךְ וּבִזְכוּת.

Noto Rashi Hebrew

Hebrew Script · Rashi · Traditional Commentarial Style

The Rashi style traces its origins to the scribal tradition used in biblical and Talmudic commentaries. Its distinct semi-cursive forms are instantly recognizable.

כָּל בְּנֵי הָאָדָם נוֹלְדוּ בְּנֵי חֹרִין, וְשָׁוִים בְּעֶרֶךְ וּבִזְכוּת.

About Clarity

Clarity is a multilingual typography framework built around Google's Noto font collection, designed for clarity, consistency, and ease of use across languages and devices.

Goals

  • Provide beautiful, readable typography for major world writing systems
  • Ensure consistent rendering across browsers and platforms
  • Offer instant theme switching with persistent preferences
  • Remain entirely self-contained — no build tools, no dependencies
  • Stay lightweight, fast, and easy to modify

Frequently Asked Questions

What writing systems are supported?
Latin, Armenian, Hebrew (including Rashi style), Arabic (Sans, Kufi, Naskh), Urdu (Nastaliq), and Color Emoji.
Do I need to install anything?
No. Everything runs directly in your browser. Fonts load from Google Fonts automatically on first use.
Can I use this offline?
Yes, once fonts have loaded at least once. However, Google Fonts must be reachable on first load.
How do I add my own content?
Edit the HTML inside the <main> section. Each page is a <div class="page"> block.

Technical Notes

All theme colors are defined as CSS custom properties at the top of the stylesheet. Adding a new theme requires only adding a new [data-theme="theme-name"] { ... } block with the ten color variables defined. The rest of the interface adapts automatically.

Font loading detection checks each font family as it loads from Google Fonts. The loading screen updates progressively so you always know which writing systems are ready. Once fonts are cached, subsequent loads are nearly instant.

Page navigation swaps content entirely in the browser without reloading, giving smooth fade transitions between pages. Your selected theme preference is saved automatically to your browser's local storage and restored on every visit.
