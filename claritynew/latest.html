Welcome to Clarity

Clarity is a multilingual typography framework built exclusively on the Noto font family — with no system fonts used anywhere and Noto Sans Math placed last in the fallback chain to prevent Arabic and complex scripts from being broken by Math's limited glyph set.

About This Framework

Designed for clarity across writing systems. Every font is served with its actual supported axes. The space character (U+0020) always renders from core fonts, never from emoji or Math. Noto Sans Math is placed intentionally LAST so it only renders mathematical symbols that no other font provides — Arabic, Hebrew, Devanagari, and all other scripts resolve from their dedicated fonts first.

Expanded Script Support

This version adds five additional writing systems: Deseret, Duployan, Sundanese, Dives Akuru, and Tangut. All are placed in the fallback chain before Mono and Math, ensuring they render correctly without interference.

Complete Fallback Order

Core → Display → Devanagari → Arabic/Hebrew/Armenian → Deseret → Duployan → Sundanese → Dives Akuru → Tangut → Mono → Math → Emoji

By placing Noto Sans Math after every script font, Arabic and other complex scripts will always use their dedicated fonts. Math only catches mathematical symbols — it will never break Arabic text.

Typography & Font Descriptions

Noto Sans Math — Placement Explained

Noto Sans Math contains almost exclusively mathematical glyphs. It lacks Arabic, Hebrew, Devanagari, and most standard characters. When placed earlier in the fallback chain, the browser would attempt to use it for those scripts and display empty boxes or broken characters. It is now placed immediately before Noto Color Emoji so it only applies to mathematical notation — all other scripts are unaffected and render from their own dedicated fonts.

Axis Support Summary

Core & Display fonts: wght ✅ wdth ✅ ital ✅

Devanagari / Arabic / Hebrew / Armenian: wght ✅ wdth ✅ ital ❌

Deseret: Full variable weight and width axes

Duployan: Only weights 400 and 700 available — no width or italic axes

Sundanese: Weight range 400–700 — no width or italic axes

Dives Akuru / Tangut: Full variable weight and width axes, Serif style

Noto Sans Math: wght = 400 only, wdth ❌ ital ❌ — use class="font-math" explicitly

Font Loading Behavior

Because this framework uses no system fonts at all, every glyph must be downloaded from Google Fonts before it can display. Less common scripts like Deseret, Duployan, Sundanese, Dives Akuru, and Tangut contain large numbers of unique glyphs and may take longer to load. Temporary empty boxes ("tofu") are normal during loading — the notice and loading screen will disappear automatically when all resources are ready.

All font-family declarations follow the identical fallback order throughout the entire framework. There are no generic system font names anywhere — every entry is an explicit Noto font name. This guarantees consistent rendering across all devices but means glyphs not present in any downloaded font file will display as empty boxes until their specific font finishes loading.

Supported Writing Systems

Core & General Scripts

Latin, Cyrillic, Greek, and extended Latin coverage is provided by Noto Sans, Noto Serif, and their Display variants. These are listed first in the fallback chain and provide the base character set for most text.

South Asian Scripts

Devanagari — Supported by both Sans and Serif variants. Full weight and width axes.

Middle Eastern Scripts

Arabic — Sans Arabic, Kufi, Naskh, and Nastaliq Urdu provide comprehensive coverage across calligraphic styles. Weight ranges vary by variant.

Hebrew — Sans, Serif, and Rashi variants. Full weight and width axes.

Armenian — Sans and Serif variants. Full weight and width axes.

Added Scripts

Deseret — Also known as the Mormon alphabet. Full variable weight and width axes.

Duployan — A shorthand writing system. Only Regular (400) and Bold (700) available.

Sundanese — Script used for the Sundanese language. Weight range 400–700.

Dives Akuru — Historical script from the Maldives. Serif style, full variable axes.

Tangut — Historical script of the Western Xia empire. Serif style, full variable axes.

Special Purpose

Noto Sans Math — Mathematical symbols and operators. Always use explicit class="font-math". Fixed weight 400.

Noto Color Emoji — Color emoji glyphs. Always last in the chain.

Script fonts load in stages by Unicode range — Latin and common characters appear first, followed by regional scripts, then historical and special-purpose scripts. Deseret, Duployan, Sundanese, Dives Akuru, and Tangut may take the longest to display due to larger file sizes and fewer cached occurrences.

Important: Math Font Position

Because Math comes after Arabic, Hebrew, Devanagari, and all other scripts, it will never be used to render Arabic or non‑mathematical text. To display mathematical symbols, apply the class="font-math" explicitly — otherwise the font will only be used as a last resort for math‑specific Unicode code points.

Command parsing automatically clamps values to each font's documented support range. Values outside a font's published range are silently adjusted to the nearest valid value — preventing unsupported axis combinations from triggering unintended fallback behavior.

Frequently Asked Questions

Why was Noto Sans Math moved to the end? expand_more
Noto Sans Math contains almost no Arabic, Hebrew, or Devanagari glyphs. When placed earlier in the fallback chain, the browser would attempt to use it for those scripts and display empty boxes or broken characters. By placing it after all script fonts and immediately before Emoji, Math only renders mathematical symbols — all other text resolves from its correct dedicated font.
How do I use mathematical notation now? expand_more
Apply the class="font-math" directly to math elements. This class has Math as its first (and only non‑emoji) font, so equations will render correctly. Without this class, math symbols still work via fallback — but regular text will always prefer the correct script font first.
Why do I see empty boxes for Deseret/Duployan/Sundanese/Dives Akuru/Tangut? expand_more
These scripts have large glyph sets and are downloaded separately. No system fonts are used anywhere — every glyph must be downloaded before it can display. The loading screen and tofu notice will disappear automatically when all 24 font resources are fully ready.
Will system fonts ever be used as fallbacks? expand_more
No. There are no generic font families (sans-serif, serif, monospace) or system font names anywhere in this website's CSS. Every font-family declaration lists only Noto fonts. If a glyph is missing from all downloaded Noto resources, you will see tofu rather than a system font substitution — this is intentional to ensure consistent typography across all devices.
