Welcome to Clarity

Clarity is a multilingual typography framework built exclusively on the Noto font family — with no system fonts used anywhere in the entire website. Every character, space, and glyph renders from Noto fonts only.

About This Framework

Designed for clarity across writing systems. Every font is served with its actual supported axes — no italics are applied to fonts that do not support them, and weight ranges are constrained where the font itself is limited. The space character (U+0020) always renders from core fonts, never from emoji.

Noto Sans Math is included for mathematical notation and formula display — it supports only weight 400 (Regular), and does not provide width or italic axes. All math content uses this font exclusively.

Typography & Font Descriptions

Core Text Fonts

Noto Sans — A sans‑serif design optimized for body text across all sizes. Supports full weight range (100–900), width axis (62.5–100), and italics. Primary source for consistent space character metrics. This font is listed first in every font‑family declaration to ensure consistent spacing and punctuation rendering.

Noto Serif — A serif design for body text. Matches the same axes and metrics as Noto Sans, serving as the primary serif fallback for spacing and punctuation.

Display Fonts — For Larger Sizes

Noto Sans Display — An unmodulated (sans‑serif) design for texts in larger font sizes in the European Latin script and in Cyrillic, Greek. Italic styles, multiple weights and widths, 3,316 glyphs. Intended for headings and display text.

Noto Serif Display — A modulated (serif) design for texts in larger font sizes. Italic styles, multiple weights and widths, 3,256 glyphs. Optimized for headings and titles.

Noto Sans Math — Mathematical Notation

Noto Sans Math — A font specifically designed for mathematical formulas, equations, and technical notation. Only supports weight 400 (Regular) — it does not provide variable weight, width, or italic axes. This font is placed after Devanagari variants but before Mono in the fallback chain, ensuring mathematical symbols resolve correctly while preserving standard text metrics. When using mathematical notation, explicitly apply the .font-math class to guarantee proper glyph selection.

Because Noto Sans Math has no variable axes, weight, width, and italic commands will have no effect on math‑tagged text — the font will always display at its fixed 400 weight.

Devanagari — Indic Script

Noto Sans Devanagari — An unmodulated design for texts in the Indic Devanagari script. 954 glyphs. Supports weight (100–900) and width (62.5–100) axes — no italics. Coverage: Devanagari, Vedic Extensions, Devanagari Extended, Basic Latin, General Punctuation, Common Indic Number Forms.

Noto Serif Devanagari — A modulated design for texts in the Indic Devanagari script. 871 glyphs. Supports weight (100–900) and width (62.5–100) axes — no italics. Unicode coverage matches Sans Devanagari across 6 blocks.

⚠️ No System Font Policy

This website does not use any operating system fonts — no sans-serif, serif, monospace, or other generic fallbacks appear anywhere in the CSS. Every font-family declaration consists exclusively of Noto fonts, ending with Noto Color Emoji. This guarantees consistent rendering across all devices and operating systems, but it also means all glyphs must be downloaded before they can display. Temporary tofu boxes are normal during the loading period.

Command Reference

Control font properties with inline commands. Both numbers and official Google Font names are accepted. Width and weight commands work on all Devanagari variants; italics are silently ignored where fonts do not support them. Commands applied to mathematical notation will have no effect — Noto Sans Math is fixed at 400 weight.

Type commands above to preview…
Commands:
/wght [value or name] — Thin(100) ExtraLight(200) Light(300) Regular(400) Medium(500) SemiBold(600) Bold(700) ExtraBold(800) Black(900)
/wdth [value or name] — ExtraCondensed(62.5) Condensed(75) SemiCondensed(87.5) Normal(100)
/ital enable|disable — Core & Display fonts only (ignored by Devanagari, Mono, Math, Script fonts)
/normal — Reset all to defaults (400, 100, italic off)

Usage Examples

  • /wght 300 /wdth 87.5 Devanagari text — Light weight, SemiCondensed width
  • /wght Bold Heading Text — Bold weight, normal width
  • /ital enable Italic heading — Italic on core or Display fonts
  • /normal Plain text at Regular weight — Reset all axes to default values
  • Mathematical notation — commands ignored — Math always renders at weight 400, normal width, no italics

Important Limitations

Devanagari Sans and Serif support width and weight but NOT italics — any /ital command has no effect on those fonts. Naskh and Nastaliq weights are clamped to 400–700. Noto Sans Math ignores all commands entirely — it is permanently fixed at weight 400 with no width or italic variations available. Noto Color Emoji also ignores all font axis commands entirely.

Font Fallback Order — No System Fonts

Every font-family declaration follows this exact chain with no generic or system fallbacks included:

  1. Core text fonts (Noto Sans → Noto Serif)
  2. Display fonts (Noto Sans Display → Noto Serif Display)
  3. Devanagari fonts
  4. Noto Sans Math
  5. Noto Sans Mono
  6. Script fonts (Armenian, Hebrew, Arabic variants)
  7. Noto Color Emoji — always last

This ordering guarantees U+0020 space characters always render from core fonts, never from emoji or script fonts. It also means glyphs not present in any downloaded Noto font will display as empty boxes (tofu) until the necessary font resource finishes loading.

Command parsing logic automatically clamps values to supported ranges per font family. Values outside a font's documented support range are silently adjusted to the nearest valid value. This prevents unsupported axes from requesting invalid font instances or triggering system fallback fonts.

Frequently Asked Questions

Why do I see empty boxes or "tofu"? expand_more
This framework uses no system fonts at all. Every glyph must be downloaded from Google Fonts before it can display. Until each font file finishes loading, characters not yet available may appear as empty boxes (often called "tofu"). This is normal — the loading screen and warning notice will disappear once all resources are ready. Script fonts and mathematical notation take longest to load because they contain many unique glyphs.
What is Noto Sans Math and why is it different? expand_more
Noto Sans Math is a specialized font designed exclusively for mathematical symbols, equations, and formula notation. Unlike other Noto fonts, it only supports weight 400 (Regular) with no width axis or italics. It is placed in the fallback chain specifically to catch mathematical glyphs that other fonts do not provide, but it will always display at a single weight regardless of commands applied.
What themes are available? expand_more
Eleven themes are included: Light (default), Dark, Electric, Sunset, Forest, Pastel, Paper, Contrast, Tsartnoc, Plum, and Seascape. Your selection is saved automatically in browser storage and persists across visits.
Contrast vs Tsartnoc — what's the difference? expand_more
Contrast: Pure white text on pure black background — cyan, yellow, and magenta accents for maximum visibility.
Tsartnoc: Pure black text on pure white — blue, green, and red accents. "Tsartnoc" is simply "Contrast" spelled backward.
Why are some fonts missing italic support? expand_more
Only core fonts (Sans / Serif) and Display fonts (Sans Display / Serif Display) include italics. Devanagari, Mono, Math, Armenian, Hebrew, and Arabic fonts do not provide an italic axis — this framework does not simulate or force italics where the font itself does not support it.
How is the space character (U+0020) protected? expand_more
Font family ordering guarantees the space character always renders from a core font (Noto Sans / Serif / Mono / Display). Devanagari, Math, and other script fonts appear afterward. Noto Color Emoji is listed LAST and only renders emoji‑specific Unicode ranges — it never supplies the space character.
Will system fonts ever be used as fallbacks? expand_more
No. There are no generic font families (sans-serif, serif, monospace) or system font names anywhere in this website's CSS. Every font-family declaration lists only Noto fonts. If a glyph is missing from all downloaded Noto resources, you will see tofu rather than a system font substitution — this is intentional to ensure consistent typography across all devices.
