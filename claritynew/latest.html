Welcome to Clarity

A thoughtfully designed, single-file website built with pure HTML, modern CSS, and lightweight JavaScript — featuring the comprehensive Noto font family including Armenian script support, three theme modes, and Material Symbols icons. Everything you see lives in one file for maximum simplicity and portability.

star Font Command System

Clarity supports inline font commands that are invisible in the source but change how text is displayed. Commands affect the text that follows them until another command is encountered.

Source: /serif Hello, /sansserif world! /normal
/serif Hello, /sansserif world! /normal

Available Commands

  • /serif — Use Noto Serif for following text
  • /sansserif — Use Noto Sans for following text
  • /monospace — Use Noto Sans Mono for following text
  • /emoji — Force Noto Color Emoji for following text
  • /noemoji — Disable emoji rendering (default state)
  • /normal — Reset to default font, regardless of prior command

palette Three Theme Modes

Choose your appearance using the theme buttons in the navigation bar:

  • Light Mode — Clean white background, high contrast text
  • Dark Mode — Deep blue-gray background, soft white text
  • Sepia Mode — Warm paper tone, reduced contrast for comfortable reading

Your selection is saved automatically and restored on your next visit.

About Clarity

Clarity demonstrates how much can be achieved with a single HTML file and a commitment to good typography. It includes comprehensive script support — including Armenian — alongside Latin and emoji support.

Design Philosophy

Good typography should be universal. The Noto font family was created to provide high-quality, open-source typefaces for every language and writing system on Earth. By including Armenian variants alongside standard Latin fonts, text remains beautifully rendered regardless of script.

Font Management & Emoji Policy

Noto Color Emoji is included but never used by default. Standard text never renders emoji symbols. Use the /emoji command to force Noto Color Emoji. Use /noemoji or /normal to return to standard typography.

Frequently Asked Questions

Answers to common questions about Clarity — including expanded script support.

question_mark What script families are supported?

Clarity now includes both Noto Sans Armenian and Noto Serif Armenian alongside the standard Latin collection. This ensures Armenian text displays beautifully in both sans-serif and serif forms, matching the typographic style of the surrounding content.

question_mark How do the font commands work?

Commands such as /serif, /sansserif, /monospace, /emoji, /noemoji, and /normal are parsed invisibly within your text. They change the active font for all text that follows until another command is encountered. Commands do not appear in rendered output.

question_mark Why include Armenian variants separately?

Armenian is a distinct writing system with its own letterforms. By including dedicated Armenian font files, text renders at optimal quality and weight — not as fallback glyphs. Sans-serif and serif variants are both provided so Armenian content can match the typographic tone of the document.
