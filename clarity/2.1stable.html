What's New — Version 2.1 (Stable)

check_circle Nushu Fixed + Global Fonts + Yezidi Added

Three major improvements in one release! Nushu now displays perfectly, every UI element uses the full font stack, and Yezidi script joins the collection!

Changes in v2.1

  • buildNushu Display Fixed: Added !important priority to Nushu font class and included it in ALL font stacks — page, editor, preview, headers. Now renders everywhere ✅
  • font_downloadGlobal Font Stack Applied: body, html, button, input, textarea, select, option, pre, code, samp, kbd — EVERY element now includes ALL fonts. No text is ever unstyled!
  • add_fontNoto Serif Yezidi Added: Yezidi script — weight 400–700. Sample: 𐺍𐺁𐺄𐺀 — auto-renders! ✨
  • linkFont Link Updated: Added Noto Serif Yezidi to the Google Fonts request.
  • labelVersion Bumped: v2.0 → v2.1 ✅

About Yezidi Script

The Yezidi script is used to write the Kurdish dialect of the Yezidi community. It is a unique alphabet with its own distinct characters — preserved digitally in Noto Serif Yezidi.
