Overview

Welcome to Clarity — a professional web design framework and template built with simplicity, consistency, and readability as its core principles.

With the addition of Noto Serif JP and Noto Serif KR in v1.7, Clarity now provides both Sans and Serif variants for Japanese and Korean.

  • Ethiopic: የሰውል (auto)

  • Latin Sans: AaLl
New Commands: /japan serif → Japanese Serif · /korea serif → Korean Serif. Use /japan / /korea for Sans variants.

Typography — Serif Variants for Japanese & Korean

Clarity now loads seven font families from the Noto collection:

  • Noto Sans: Latin, Greek, Cyrillic — primary interface font.
  • Noto Serif: Latin headings and titles — elegant distinction.
  • Noto Sans JP: Japanese Sans — activated via /japan.
  • Noto Serif JP: Japanese Serif — activated via /japan serif.
  • Noto Sans KR: Korean Sans — activated via /korea.
  • Noto Serif KR: Korean Serif — activated via /korea serif.
  • Noto Sans Ethiopic: Ethiopic script — auto-activated, no command needed.

What's New in v1.7

What's New — Version 1.7 (Stable)

check_circle Noto Serif JP & KR Added

Clarity v1.7 adds serif variants for Japanese and Korean. Use /japan serif and /korea serif to select them. Original sans commands remain: /japan and /korea.

Changes in v1.7

  • add_fontFont Link Updated: Added Noto Serif JP (wght@200..900) & Noto Serif KR (wght@200..900).
  • font_downloadTwo New Font Families: Noto Serif JP and Noto Serif KR now available alongside all existing fonts.
  • terminalTwo New Commands: /japan serif → Japanese Serif · /korea serif → Korean Serif.
  • ruleBackward Compatible: Existing /japan and /korea still work → select Sans variants.
  • labelVersion Bumped: v1.6 → v1.7 ✅ (new feature = version number increased)

Command Behavior Explained

  • /japan → Noto Sans JP (Sans) — unchanged from before
  • /japan serif → Noto Serif JP — NEW
  • /korea → Noto Sans KR (Sans) — unchanged from before
  • /korea serif → Noto Serif KR — NEW

Commands are now two-tiered: base command selects Sans; command + "serif" selects Serif.

Font Loading Details

The updated link requests SEVEN families in a single efficient request:

  • Noto Serif JP — 200 to 900 weight ✅
  • Noto Serif KR — 200 to 900 weight ✅
  • Noto Sans Ethiopic — 100 to 900 weight ✅
  • Noto Sans JP — 100 to 900 weight ✅
  • Noto Sans KR — 100 to 900 weight ✅
  • Noto Sans — normal & italic, 100 to 900 ✅
  • Noto Serif — normal & italic, 100 to 900 ✅

About Clarity

Clarity is an open web design template created to demonstrate professional web design using standard HTML, CSS, and JavaScript — no frameworks or build tools required.

Versioning Rule

Every new feature increases the version number.

v1.0 → v1.1 → v1.2 → v1.3 → v1.4 → v1.5 → v1.6 → v1.7 — each addition increments the version clearly.

Supported Fonts & Commands

  • Latin: Sans (/normal /sansserif), Serif (/serif)
  • Japanese: Sans (/japan), Serif (/japan serif)
  • Korean: Sans (/korea), Serif (/korea serif)
  • Ethiopic: Sans (auto-activated)
