What's New in v2.5

What's New — Version 2.5 (Stable)

check_circle Emoji Support + Thai Default → Sans!

Clarity v2.5 adds Noto Color Emoji (auto-renders in full color) + Noto Emoji (outline style via /monochrome). Thai now defaults to Noto Sans Thai globally!

Changes in v2.5

  • emoji_eventsNoto Color Emoji Added: Full-color emoji font. Auto-renders everywhere! Sample: 🎶🎷🐛 ✨
  • paletteNoto Emoji Added: Monochrome/outline emoji font. New command: /monochrome ✨
  • ruleThai Default Changed: Thai now uses Noto Sans Thai everywhere. Serif variant available via /thai serif ✅
  • linkFont Link Updated: 2 emoji families added → 22 total font families!
  • font_downloadGlobal Font Stack Updated: Color Emoji renders automatically everywhere — page, editor, preview, headers!
  • terminalNew Commands: /monochrome → Noto Emoji · /thai serif → Noto Serif Thai
  • labelVersion Bumped: v2.4 → v2.5 ✅

About Emoji Fonts

Noto Color Emoji provides full-color emoji that render automatically — no command needed. Noto Emoji is the outline-style monochrome variant, activated with /monochrome.

About Thai Default Change

Thai now defaults to Noto Sans Thai (clean, modern sans-serif style) instead of Serif. Use /thai serif when you want the traditional look. Looped variant remains available via /looped.
