Overview

Welcome to Clarity — a professional web design framework and template built with simplicity, consistency, and readability as its core principles.

With the addition of the Editor page in v1.3, and Material Symbols Icons in v1.4, Clarity now provides a complete, professional environment — all icons loaded from Google Fonts Icons, perfectly matching your selected theme.

  • languageGlobal Typography: Noto Sans, Noto Serif, and Noto Sans JP — unified typography for every language.
  • edit_noteInline Font Commands: Change font anywhere in your text — /serif, /sansserif, /japan, /normal.
  • paletteDual Theme Support: Light and dark modes with one-click toggle, auto-saved preference.
  • devicesResponsive by Default: Layouts adapt fluidly to any screen size.
  • codeStandards Compliant: Built with semantic HTML, modular CSS, and unobtrusive JavaScript.

About Clarity

Clarity is an open web design template created to demonstrate professional web design using standard HTML, CSS, and JavaScript — no frameworks or build tools required.

Versioning Rule

Every new feature increases the version number.

v1.0 → v1.1 → v1.2 → v1.3 → v1.4 — each addition increments the version clearly. Backward compatibility is maintained throughout the v1.x series.

Philosophy

  • Web design should be understandable from first principles — no frameworks required.
  • Global typography through Noto fonts — designed for every language on Earth.
  • Professional icons through Material Symbols — consistent, scalable, theme-aware.
  • Structure, presentation, and behavior remain strictly separated.
  • Accessibility is not optional — color contrast, semantic structure, keyboard navigation.
