What's New in v1.8

What's New — Version 1.8 (Stable)

check_circle Simplified & Traditional Chinese Added

Clarity v1.8 adds Noto Sans SC (Simplified) and Noto Sans TC (Traditional). /china selects SC; /taiwan or /macau select TC. Serif variants reserved for future use.

Changes in v1.8

  • add_fontFont Link Updated: Added Noto+Sans+SC and Noto+Sans TC (wght@100..900 each).
  • font_downloadDefault Font Stack Updated: Noto Sans, Noto Serif, Noto Sans Ethiopic, Noto Sans SC.
  • terminalNew Commands: /china · /taiwan · /macau (and their "serif" variants reserved).
  • text_fieldsSample Text: 人生而自 — provided for both SC and TC.
  • labelVersion Bumped: v1.7 → v1.8

Command Aliases

  • /taiwan and /macau → both map to Noto Sans TC (same font)
  • /china serif / /taiwan serif / /macau serif → reserved for future Serif fonts

About Clarity

Clarity is an open typography template built with standard HTML, CSS, JavaScript — no frameworks.

Versioning Rule

Every new feature increases the version number.

v1.0 → v1.1 → ... → v1.8 — each addition increments the version clearly.

  • Korean: Sans / Serif
  • Chinese: Simplified (SC) / Traditional (TC, Taiwan/Macau)
