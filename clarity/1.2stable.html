Overview

Welcome to Clarity — a professional web design framework and template built with simplicity, consistency, and readability as its core principles. Clarity has been developed to provide a solid foundation upon which any kind of web project can be built.

With the addition of Noto Sans JP in v1.2, Clarity now offers comprehensive support for Japanese alongside Latin and serif typography — all from the Noto font family, ensuring consistent visual harmony across every language.

Design Principles

  • Global Typography: Noto Sans (with JP extension) for body text, Noto Serif for headings — unified typography for every language.
  • Dual Theme Support: Light and dark modes with one-click toggle, system preference matching, and auto-saved preference.
  • Consistency Everywhere: Spacing, sizing, and styling follow consistent patterns throughout.
  • Responsive by Default: Layouts adapt fluidly to any screen size.
  • Standards Compliant: Built with semantic HTML, modular CSS, and unobtrusive JavaScript.

Features

Typography — Now with Japanese Support

Clarity now loads three font families from the Noto collection:

  • Noto Sans: Latin, Greek, Cyrillic, and extended scripts — primary interface font.
  • Noto Sans JP: Japanese kanji, hiragana, and katakana — full weight range 100–900.
  • Noto Serif: Headings and titles — provides elegant distinction from body text.

Both sans-serif families share the same design language — Japanese text flows naturally alongside Latin text without visual mismatch.

What's New — Version 1.2 (Stable)

🗾 New Feature: Noto Sans JP

Clarity v1.2 adds full Japanese language support. Noto Sans JP with weight range 100–900 now loads alongside Latin fonts — unified typography for all languages.

Changes in v1.2

  • Font Link Updated: Added Noto+Sans+JP:wght@100..900 to the Google Fonts request.
  • Font Stack Updated: Body font changed to "Noto Sans", "Noto Sans JP", sans-serif — Japanese text renders with matching style.
  • Performance Preserved: preconnect hints remain — fonts load fast with zero render-blocking delay.
  • Version Bumped: v1.1 → v1.2 — new feature = version number increased ✅

Font Loading Details

The updated link requests three families in a single efficient request:

  • Noto Sans JP — 100 to 900 weight
  • Noto Sans — normal & italic, 100 to 900
  • Noto Serif — normal & italic, 100 to 900

Google automatically serves the correct character subsets — only the glyphs needed for the page's language are downloaded. Efficient, global, and elegant.

About Clarity

Clarity is an open web design template created to demonstrate professional web design using standard HTML, CSS, and JavaScript — no frameworks or build tools required.

Versioning Rule

Every new feature increases the version number.

v1.0 → v1.1 (Dark Mode) → v1.2 (Noto Sans JP) — each addition increments the version clearly. Backward compatibility is maintained throughout the v1.x series.

Philosophy

  • Web design should be understandable from first principles — no frameworks required.
  • Global typography through Noto fonts — designed for every language on Earth.
  • Structure, presentation, and behavior remain strictly separated.
  • Accessibility is not optional — color contrast, semantic structure, keyboard navigation.

Font Customization

To add more language support, simply extend the Google Fonts link with additional Noto families (Noto Sans SC, Noto Sans TC, Noto Sans KR, etc.), then update the font-family stack in the CSS to match. The entire design adapts automatically.

Getting Started

  1. Copy the full HTML code.
  2. Paste into any plain text editor.
  3. Save as index.html.
  4. Open in any browser — fonts, icons, dark mode, and navigation all work instantly.
