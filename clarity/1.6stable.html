Overview

Welcome to Clarity — a professional web design framework and template built with simplicity, consistency, and readability as its core principles.

With the addition of Noto Sans KR in v1.6, Clarity now supports four writing systems — Latin, Japanese, Korean, and Ethiopic — all from the Noto font family.

Sample Text — All Four Writing Systems

  • Ethiopic: የሰውል
  • Japanese: すべて の
  • Korean: 모든인간
  • English (Latin): AaLl
Note: Ethiopic has no command — it activates automatically. Use /serif, /sansserif, /japan, /korea for explicit font switching.

Features

Typography — Now with Korean Support

Clarity now loads five font families from the Noto collection:

  • Noto Sans: Latin, Greek, Cyrillic — primary interface font.
  • Noto Serif: Headings and titles — elegant distinction.
  • Noto Sans JP: Japanese Kanji, Hiragana, Katakana — activated via /japan command.
  • Noto Sans KR: Korean Hangul — activated via /korea command.
  • Noto Sans Ethiopic: Ethiopic script — auto-activated, no command needed.

Font Commands & Behavior

  • /normal → Reset to Noto Sans (default)
  • /serif → Noto Serif
  • /sansserif → Noto Sans
  • /japan → Noto Sans JP
  • /korea → Noto Sans KR
  • Ethiopic: No command — auto-renders via font stack.

What's New — Version 1.6 (Stable)

check_circle Noto Sans KR Added

Clarity v1.6 adds full Korean language support. Noto Sans KR loads alongside Latin, Japanese, and Ethiopic fonts. Use the /korea command to switch to Korean font.

Changes in v1.6

  • add_fontFont Link Updated: Added Noto+Sans+KR:wght@100..900 to the Google Fonts request.
  • font_downloadFont Stack Extended: Body font now includes KR — "Noto Sans", "Noto Sans JP", "Noto Sans KR", "Noto Sans Ethiopic", sans-serif.
  • terminalNew Command: /korea — switches subsequent text to Noto Sans KR.
  • text_fieldsSample Text Included: 모든인간 — Korean sample text demonstrates the font.
  • labelVersion Bumped: v1.5 → v1.6 ✅ (new feature = version number increased)

Font Loading Details

The updated link requests five families in a single efficient request:

  • Noto Sans KR — 100 to 900 weight ✅
  • Noto Sans Ethiopic — 100 to 900 weight ✅
  • Noto Sans JP — 100 to 900 weight ✅
  • Noto Sans — normal & italic, 100 to 900 ✅
  • Noto Serif — normal & italic, 100 to 900 ✅

Google automatically serves only the glyphs needed for each language — efficient loading.

About Clarity

Clarity is an open web design template created to demonstrate professional web design using standard HTML, CSS, and JavaScript — no frameworks or build tools required.

Versioning Rule

Every new feature increases the version number.

v1.0 → v1.1 → v1.2 → v1.3 → v1.4 → v1.5 → v1.6 — each addition increments the version clearly. Backward compatibility is maintained throughout the v1.x series.

Supported Writing Systems

  • Latin: English and many European languages — Noto Sans / Noto Serif, via /serif /sansserif /normal.
  • Japanese: Kanji, Hiragana, Katakana — Noto Sans JP, via /japan command.
  • Korean: Hangul — Noto Sans KR, via /korea command.
  • Ethiopic: Amharic and related languages — Noto Sans Ethiopic, auto-activated.

Philosophy

  • Web design should be understandable from first principles — no frameworks required.
  • Global typography through Noto fonts — designed for every language on Earth.
  • Simple commands produce powerful results — clarity through simplicity.
