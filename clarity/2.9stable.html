/noemoji vs /emoji

  • /noemoji = Uses Noto Sans Symbols + Math fonts → plain monochrome symbols. Priority: FIRST.
  • /emoji = Uses Noto Color Emoji → colorful. Priority: FALLBACK.
  • Rule: Symbols render as plain text first; only emoji-style characters get colorful version.
