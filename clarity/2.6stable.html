What's New in v2.6

What's New — Version 2.6 (Stable)

check_circle Monospace + Highlight + Strikethrough + RGB Color!

Clarity v2.6 adds Noto Sans Mono font, ==highlight== / `code` markdown, ~~strikethrough~~ markdown, and /colorrgb #hex text coloring command!

Changes in v2.6

  • codeNoto Sans Mono Added: Monospace font, weight 100–900. Command: /monospace ✨
  • border_colorHighlight Markdown: ==text== or `` `text` `` → yellow background highlight. Adapts to light/dark mode ✨
  • strikethrough_sStrikethrough Markdown: ~~text~~ → line-through text ✨
  • paletteRGB Color Command: /colorrgb #RRGGBB sets text color. /normal resets both font and color ✨
  • rule/normal & /sansserif: Reset to default font AND default text color. /sansserif is alias for /normal ✅
  • linkFont Link Updated: Noto Sans Mono added → 23 total font families
  • labelVersion Bumped: v2.5 → v2.6 ✅

Command Usage Examples

  • /monospace → applies Noto Sans Mono to following text
  • /colorrgb #ff4444 Hello → "Hello" appears in red
  • /colorrgb #2563eb Blue → "Blue" appears in blue
  • /normal → resets font to Noto Sans AND color to default
  • /sansserif → same as /normal
