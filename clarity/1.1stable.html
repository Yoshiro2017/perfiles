Overview

Welcome to Clarity — a professional web design framework and template built with simplicity, consistency, and readability as its core principles. Clarity has been developed to provide a solid foundation upon which any kind of web project can be built, from documentation sites and dashboards to content-heavy publications and corporate portals.

The philosophy behind Clarity is straightforward: content should be presented clearly, navigation should be intuitive, and design choices should serve the information rather than distract from it. Every element — from font sizes and line heights to color selections — has been chosen with purpose. There are no decorative flourishes that serve no function; every detail contributes toward legibility and comprehension.

Design Principles

  • Readability First: Typography is the foundation of all design. Clarity uses Noto Sans for interface text and Noto Serif for headings — ensuring both structural distinction and visual harmony across every language and writing system.
  • Light & Dark Ready: Clarity now supports both light and dark modes with full color palette consistency. Your preference is remembered automatically on future visits.
  • Consistency Everywhere: Spacing, sizing, and styling follow consistent patterns throughout. Users should never have to relearn how to navigate or interpret different sections of the same experience.
  • Responsive by Default: Layouts adapt fluidly to any screen size. Whether viewed on a compact smartphone, tablet, laptop, or large desktop monitor, the content remains accessible and well-structured.
  • Standards Compliant: Built with semantic HTML, modular CSS, and unobtrusive JavaScript. Clarity follows recognized web standards to ensure broad compatibility, accessibility, and long-term maintainability.

Intended Use

Clarity serves as both a ready-to-use template and a reference implementation of good web design practices. It may be used as-is for documentation, project homepages, internal tools, or content sites. It may also be extended and customized to suit more specific requirements.

With the release of version 1.1, Dark Mode is now available. Click the moon icon in the top-right corner to toggle between light and dark themes. Your preference will be saved automatically.

Features

Clarity includes a carefully selected set of features designed to meet the needs of most web projects without unnecessary complexity. Every component and capability has been evaluated for utility, accessibility, and performance before being included.

Typography & Fonts

Clarity makes use of the Noto font family — a comprehensive, open-source collection designed to support every language and writing system. Two families are employed:

  • Noto Sans: Used for body text, navigation, buttons, and interface elements. Clean sans-serif forms ensure exceptional legibility at all sizes and weights.
  • Noto Serif: Used exclusively for headings. Carefully proportioned serifs provide visual distinction and structure while maintaining graceful scaling.

Dark Mode Support

Clarity v1.1 introduces full dual-theme support. The entire color palette is defined using CSS Custom Properties, allowing instantaneous switching between light and dark appearances without page reloads or style recalculations. Key characteristics include:

  • One Click Toggle: Click the moon/sun icon in the header to switch themes instantly.
  • Automatic Persistence: Your choice is saved to local storage. Every future visit remembers your preference.
  • System Preference Aware: On first visit, Clarity automatically matches your operating system's light/dark setting.
  • Carefully Selected Palette: Both themes maintain identical contrast ratios, spacing, and visual hierarchy — colors change, readability stays constant.
  • Smooth Transitions: All background and text colors animate gently — no jarring flashes during switch.

Interface & Icons

Material Symbols Outlined provide consistent, scalable visual indicators. Because they integrate with the font system, they match text weight and scale perfectly in both themes.

What's New — Version 1.1 (Stable)

🌙 New Feature: Dark Mode

Clarity v1.1 introduces complete dual-theme support. Toggle instantly between Light and Dark modes. Your preference is remembered automatically on every return visit.

Following the release of v1.0 Stable, this update adds the most requested feature: comprehensive Dark Mode support. Every color, border, background, and text shade has been carefully adapted to maintain perfect readability, contrast, and visual harmony in both themes. The version number has been incremented to v1.1 in accordance with our versioning rule: every new feature increases the version number.

Dark Mode Implementation

The entire color system has been rebuilt using CSS Custom Properties (variables). This means:

  • Colors are defined in exactly ONE place at the top of the stylesheet — every element references these variables rather than hardcoded values.
  • Switching themes simply swaps the variable definitions — ALL elements update instantly and consistently.
  • Transitions are smooth — backgrounds and text fade gently rather than flash, because the color change is animated.
  • Contrast is maintained perfectly — dark backgrounds use lighter text with identical readability scores.
  • Component designs remain visually identical — only the palette changes, not the layout or structure.

Behavior & Persistence

  • On First Visit: Clarity automatically detects your operating system preference — light or dark — and matches it.
  • On Manual Toggle: Click the moon/sun icon. Your choice is saved to local storage and persists across browser restarts and future visits.
  • URL Sharing: Theme preference is separate from page location. Sharing a link shares the page, not your personal theme setting.

All Changes Since v1.0

  • Version: v1.0 → v1.1 (Feature release — backward compatible)
  • Color System: Rebuilt entirely with CSS variables — light and dark palettes
  • Theme Toggle: Button added to header with moon/sun icon that updates automatically
  • Auto-Detection: Respects prefers-color-scheme on first load
  • Preference Storage: Saves selection to localStorage — remembered forever until changed
  • Smooth Transitions: Background and text colors animate during theme change
  • All Components Updated: Cards, buttons, borders, highlights — everything adapts

About Clarity

Clarity is an open web design template and reference implementation created to demonstrate how well-designed, professional web interfaces can be built using only standard, fundamental web technologies. It was developed as a practical response to the increasing complexity, dependencies, and build tooling found in many modern web frameworks.

Versioning Rule

Clarity follows a strict versioning policy established from the beginning:

Every new feature increases the version number.

From Beta → v1.0 → v1.1 and onward — each addition increments the version clearly. This ensures you always know exactly which iteration you are viewing.

Philosophy

The guiding philosophy remains unchanged:

  • Web pages should be understandable from first principles — no frameworks required.
  • Structure, presentation, and behavior remain strictly separated.
  • Design decisions should serve legibility, comprehension, and usability above all else.
  • Technology should be timeless — standards-compliant HTML, CSS, and JavaScript.
  • Accessibility is not optional — every design choice must serve all users equally.

How It Is Built

Clarity consists of HTML, CSS, and JavaScript — contained within one file for ease of use. No build tools, compilers, or dependencies are required. Fonts and icons load directly from Google Fonts.

Acknowledgments

Clarity gratefully uses Noto Fonts and Material Symbols — both freely available from Google Fonts — alongside open web standards developed by W3C and WHATWG.

Getting Started

  1. Copy the full HTML code from the source.
  2. Paste it into any plain text editor — Notepad, VS Code, Sublime, Vim, or any editor.
  3. Save the file with an .html extension.
  4. Open the file in any web browser. It will work immediately.

Using Dark Mode

Dark Mode is fully integrated and ready to use:

  • Toggle: Click the moon/sun icon in the top-right corner at any time.
  • Auto: First visit matches your system settings automatically.
  • Remembers: Your choice is saved. Every return remembers your preference.
  • Consistent: Layout, spacing, and contrast remain identical — only colors adapt.

How Everything Works

Although it appears to be multiple separate pages, everything operates within a single HTML file. Clicking navigation links hides the current section, displays the requested one, updates the address bar, and records history. Browser back/forward buttons work normally.

Customization Guide

  • Change Colors: Modify the values in the :root and [data-theme="dark"] sections at the top of the CSS. Every element updates automatically.
  • Add Content: Simply edit the text within each page section — no special formatting required.
  • Add Pages: Create a new <div class="page" id="newid"> section, then add a navigation link with data-page="newid" — everything works automatically.
  • Change Fonts: Replace the Google Fonts link and update the font-family entries — the entire structure adapts immediately.
