Overview

Welcome to Clarity — a professional web design framework and template built with simplicity, consistency, and readability as its core principles.

With the addition of the Editor page in v1.3, you can type freely, apply fonts with simple inline commands, and use Markdown formatting — all with live preview.

Design Principles

  • Global Typography: Noto Sans, Noto Serif, and Noto Sans JP — unified typography for every language.
  • Inline Font Commands: Change font anywhere in your text with simple commands — /serif, /sansserif, /japan, /normal.
  • Markdown Support: Bold, italic, headings, lists, code — all rendered instantly.
  • Dual Theme Support: Light and dark modes with one-click toggle.
  • Responsive by Default: Layouts adapt fluidly to any screen size.

What's New — Version 1.3 (Stable)

✏️ New Feature: Editor Page + Font Commands

Clarity v1.3 introduces a live Editor page with split input/preview view. Use inline commands to switch fonts anywhere in your text. Full Markdown support included.

New in This Release

  • New Page: Editor — dedicated text area with live preview, split into input and rendered output.
  • Font Commands: /serif, /sansserif, /japan, /normal — apply fonts to any text segment instantly.
  • Command Behavior: Commands affect ONLY the text that follows them until another command is encountered.
  • Markdown Support: **bold**, *italic*, headings (#), lists (- or 1.), inline `code`, and horizontal rules.
  • Auto-Update Preview: Every keystroke updates the preview instantly.
  • Version Bumped: v1.2 → v1.3 ✅ (new feature = version number increased)

Command Behavior Explained

Commands are inline and stateful. Once you use a command, that font stays active until another command replaces it.

  • Text starts as Noto Sans (default).
  • /serif → All following text becomes Serif until changed.
  • /japan → All following text becomes Japanese font until changed.
  • /normal → Resets everything back to Sans.

About Clarity

Clarity is an open web design template created to demonstrate professional web design using standard HTML, CSS, and JavaScript — no frameworks or build tools required.

Versioning Rule

Every new feature increases the version number.

v1.0 → v1.1 → v1.2 → v1.3 — each addition increments the version clearly. Backward compatibility is maintained throughout the v1.x series.

Philosophy

  • Web design should be understandable from first principles — no frameworks required.
  • Global typography through Noto fonts — designed for every language on Earth.
  • Structure, presentation, and behavior remain strictly separated.
  • Simple commands produce powerful results — clarity through simplicity.
